# 💊 PharmaStock – Pharmacy Management System

PharmaStock is a full-stack Pharmacy Management System built using the MERN Stack that helps pharmacies efficiently manage medicines, inventory, billing, sales records, and employee access through a secure and user-friendly platform.

---

## 🚀 Features

- 🔐 Secure JWT Authentication
- 👥 Role-Based Access Control (User, Admin, Super Admin)
- 💊 Medicine Inventory Management
- 📦 Stock Monitoring and Updates
- 📷 Barcode Scanner Integration
- 🧾 PDF Bill Generation
- 📊 Dashboard Analytics and Reports
- ⚠️ Low Stock Alerts
- ⏰ Medicine Expiry Tracking
- 📝 Activity Logs and Sales Tracking
- 🔒 Protected Routes and APIs

## ⚙️ Installation & Setup

### Clone the Repository

```bash
git clone https://github.com/your-username/PharmaStock.git
cd PharmaStock
```

### Backend Setup

```bash
cd backend
npm install
npm start
```

### Frontend Setup

```bash
cd frontend
npm install
npm run dev
```
